# Embudo de Ventas de Modcloth

Este proyecto es un embudo de ventas personalizado para Modcloth.com, diseñado para atraer, convertir, cerrar y fidelizar a los clientes. La estructura del proyecto incluye secciones para cada etapa del embudo, con contenido y estilos específicos para mejorar la experiencia del usuario.

## Estructura del Proyecto

- `index.html`: Página principal del embudo de ventas.
- `atraccion/`: Contiene el blog y artículos para atraer a los visitantes.
- `conversion/`: Páginas para capturar leads y convertir visitantes en clientes.
- `cierre/`: Páginas de checkout y finalización de compra.
- `fidelizacion/`: Programa de recompensas y estrategias de fidelización.
- `css/`: Archivos de estilos CSS, incluyendo estilos extravagantes.
- `js/`: Archivos de scripts JavaScript, incluyendo análisis.
- `img/`: Imágenes y gráficos utilizados en el sitio.
- `README.md`: Documentación del proyecto.

## Cómo Usar

1. Clona este repositorio en tu máquina local.
2. Abre `index.html` en tu navegador para ver el embudo de ventas.
3. Personaliza el contenido según tus necesidades.
4. Sube los cambios a GitHub y configura GitHub Pages para alojar tu sitio web.

## Personalización

- **Blog**: Añade nuevos artículos en la carpeta `atraccion/blog/` para mantener el contenido fresco y relevante.
- **Newsletter**: Personaliza la página de suscripción a la newsletter para reflejar campañas específicas.
- **Checkout**: Asegúrate de que la página de checkout sea segura y fácil de usar para mejorar la conversión.
- **Programa de Recompensas**: Detalla los beneficios y cómo funcionan las recompensas para incentivar la fidelización.

## Estilos Extravagantes

Los estilos en `css/extravagant.css` están diseñados para resaltar secciones importantes y hacer que el sitio sea visualmente atractivo. Puedes ajustar estos estilos para alinearlos con la identidad de marca de Modcloth.
